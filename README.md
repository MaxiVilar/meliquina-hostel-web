# Meliquina Hostel

## Descripción del proyecto

Meliquina Hostel es una página web sencilla creada como proyecto
de práctica de desarrollo web.

El sitio presenta información sobre un hostel ubicado en
Villa Meliquina, Neuquén.

Los visitantes pueden conocer las habitaciones disponibles,
leer algunas reseñas y enviar una consulta mediante un
formulario de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Formspree

## Secciones de la página

- Inicio
- Habitaciones
- Reseñas
- Contacto

## Diseño

La página cuenta con un diseño adaptable para computadoras,
tablets y teléfonos celulares.

Se utilizaron Flexbox para las tarjetas de habitaciones y
CSS Grid para organizar las reseñas.

## Autor

Proyecto realizado como práctica de desarrollo web.
